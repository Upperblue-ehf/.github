# Upperblue

Upperblue brings Icelandic environmental and infrastructure data together in maps and an API. Explore weather, earthquakes, roads, and coastal conditions across Iceland at [upperblue.com](https://upperblue.com).

## Try the API in Python

Where did Iceland shake on a given day? When is high tide in Reykjavík? The [Upperblue API demo](https://github.com/Upperblue-ehf/upperblue-api-demo) answers both questions with short Python examples. Run them with the included data, then use a REST API key to explore another date.
